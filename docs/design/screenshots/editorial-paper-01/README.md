## 与上一版的差异

- 画布由 Violet 配色的奶油白 + 紫色主行动，改为暖纸白 + 墨黑行动 + 薄荷状态。
- 衬线标题改为系统无衬线 semibold，负字距。
- 卡片 + 阴影改为留白 + 0.5pt 分隔线。
- iOS 26 悬浮玻璃 Tab 栏改为自绘平铺栏（push 后自动隐藏）。
- 用户图片取代插画成为主视觉；未上传图片的心愿只显示主题色细线与占位图标。
